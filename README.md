# Weekfold

A quiet weekly reflection app for the Mac. Gather your week, look at it, and fold it. Everything stays on your Mac.

**Home:** https://hudsonrivercrossing.github.io/weekfold/

Weekfold is in a small private beta. The public release is planned for December.

## Feedback

Testing a beta? [Open an issue](../../issues/new?template=beta-feedback.md) with the beta-feedback template. Keep private things out: describe what you saw instead of pasting real notes, passages, health data or keys.

This repository holds only the homepage. The app's code is not public.
